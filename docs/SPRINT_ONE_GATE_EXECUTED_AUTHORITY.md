## Non-negotiable architecture

1. **One engine authority.** Runtime law loads from the content-addressed installed engine recorded by deployment truth. No implicit repository, worktree, legacy, or sibling-seat fallback.
2. **Typed normalization.** A shim translates native events using a shared schema keyed by (tool, argument) to value kind. A global list of path-looking names is not a schema.
3. **No shim law.** Scope, egress, read/write classification, governance closure, degraded posture, timeout/retry policy, remedies, escalation content, and witnessing semantics live outside shims.
4. **Native rendering only.** A shim may map a shared verdict to its harness's exit code or deny payload. It may not reinterpret the verdict.
5. **Three independent release bars.** Shared-predicate corpus, adapter conformance, and installed-execution proof are separate; none may stand in for another.
6. **Deployment is activation.** Binary, hooks, shared engine, adapter declarations, and grant-envelope generation/digest form one vault-ratified set.

## Ordered implementation

### S1 - Loader authority

Pin every adapter to the installed shared engine, remove implicit working-tree fallbacks, fail closed when authority is absent, and prove a branch-local decoy cannot execute.

**Exit:** every registered gate reports one installed engine digest; changing a checkout cannot change a verdict before governed deployment.

### S2 - Typed event normalization

Define shared value kinds for filesystem paths, path lists, repository identities, globs, regexes, commands, patches, and inert text. Map native tool schemas by (tool, argument), preserving both historical pattern incidents.

**Exit:** each adapter's extraction is driven by the differential; unmapped consequential arguments are indeterminate/fail-closed rather than silently absent.

### S3 - Remove forked predicates

Delete Gemini's four second implementations, unify no-verdict behavior, and move duplicated refusal/witness/tally/gate-self calls into the shared mechanism.

**Exit:** zero forked decision predicates.

### S4 - Learn the common classifier

Use the corrected corpus as the shared-predicate specification. Fix false-positive, interpreter-mediated, variable-target, and gate-self cases in the common implementation. Every case must reproduce its citation and carry a negative control.

**Exit:** zero wrong corpus cases.

### S5 - Thin-shim completion

Move Claude's remaining decision-bearing shell classifier into the shared engine. Reduce every shim to parse/normalize, identity/registration facts, transport, and native rendering. Treat attribution-only fields as metadata.

**Exit:** 0% seat-local law-bearing code.

### S6 - Ratified deployment and live proof

Bind binary, hook entrypoints, shared engine, adapter schema, and effective grant-envelope digest into one deployment record. Verify before activation and periodically. Reconcile begin/outcome pairs and surface stale or mismatched evidence as MISWIRED.

**Exit:** source, merged, deployed, loaded, and observed are separately evidenced and converge on one ratified build.
